CSS Float & Clear

Demonstration of Float and Clear Properties

Float Left

Float Left

The float property allows an element to move to the left or right side of its container. When an element is floated to the left, the text can flow around it. This technique was commonly used for creating layouts and positioning images beside text.

Float Right

Float Right

An element can also be floated to the right using the float property. The surrounding text flows around the floated element. Float can be useful for simple layouts and content positioning.

Clear Property

The clear property prevents an element from being positioned next to floated elements.

CSS Overflow Properties

Demonstrating visible, hidden, scroll and auto overflow

Overflow Demonstration

The CSS overflow property controls what happens when content is larger than its container.

Overflow: Visible

This content is intentionally longer than the box. With visible overflow, content can extend outside the boundaries of the container. More text is added to demonstrate the effect.
overflow: visible

Overflow: Hidden

This content is intentionally longer than the box. With hidden overflow, content that exceeds the container is clipped and cannot be seen outside it. Additional text will be hidden.
overflow: hidden

Overflow: Scroll

This container always provides scrollbars when the content exceeds its available space. You can scroll through the content to see everything inside the box. Additional information is included here.
overflow: scroll

Overflow: Auto

Auto overflow adds scrollbars only when necessary. If the content fits inside the container, scrollbars are not required. This example contains extra content. More text is included for demonstration.
overflow: auto

Horizontal Overflow

This is a very wide content area demonstrating horizontal scrolling using overflow-x: auto.
overflow-x: auto

Vertical Overflow

Content is arranged vertically inside this container. When the content becomes taller than the available height, vertical scrolling becomes available. More content is added to demonstrate the effect. Scroll down to view additional content. This is another line of content.
overflow-y: auto

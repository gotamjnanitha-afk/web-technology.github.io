2. CSS Specificity

When multiple CSS rules target the same element, the more specific selector gets higher priority.

This text demonstrates specificity.

Selector Priority

  • Element Selector → Lower specificity
  • Class Selector → Higher specificity
  • ID Selector → Higher priority than class
  • Inline Style → Very high specificity

CSS Cascade Result

CSS inheritance passes selected properties from parent to child, while specificity determines which conflicting rule is applied.

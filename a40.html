CSS Image Hover Effects

Interactive Image Effects Using CSS

Hover Over the Images

Move your mouse over each image to see different CSS hover effects such as zoom, rotation, grayscale and brightness.

Zoom Effect

Image smoothly becomes larger.

transform: scale()

Rotate Effect

Image rotates slightly on hover.

transform: rotate()

Grayscale Effect

Image changes to black and white.

filter: grayscale()

Brightness Effect

Image becomes darker on hover.

filter: brightness()

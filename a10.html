CSS Pseudo-Classes

Hover • Active • Focus • Visited

:hover

The hover pseudo-class applies a style when the mouse pointer is placed over an element.

:active

The active pseudo-class applies a style while an element is being clicked.

:focus

The focus pseudo-class applies a style when an input element receives focus.

:visited

The visited pseudo-class changes the appearance of a link after it has been visited.

Z-Index and Stacking Order

The z-index property controls which positioned element appears in front of another when elements overlap.

Overlapping Elements

Box 2
z-index: 2

Box 1 z-index: 1
Box 2 z-index: 2
Box 3 z-index: 3
Box 4 z-index: 4

A higher z-index value places an element above an element with a lower z-index value within the same stacking context.

z-index: 1 → 4
